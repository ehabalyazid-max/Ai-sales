# 🌸 Smell & Smile AI Sales, Lead Scraper & WhatsApp Agent (B2B & B2C)

نظام الذكاء الاصطناعي المتكامل للمبيعات، سحب داتا الشركات السعودية، الإرسال التلقائي عبر الواتساب (باستخدام كود الربط Pairing Code من 8 أرقام بدون كاميرا أو الإرسال الآمن بضغطة زر)، ومتابعة الريفيل الشهري لبراند **Smell & Smile (سميل أند سمايل)**.

---

## ✨ مميزات المشروع المبني في هذا المستودع

1. **🇸🇦 قاعدة بيانات حقيقية جاهزة (58 عميل شركات سعودي B2B):**
   - **20 مجمع وعيادة طبية وأسنان وتجميل** في الرياض والخرج.
   - **9 فنادق وأجنحة فندقية مخدومة** في جدة والرياض والدمام.
   - **15 كافيه ومطعم ولاونج راقي** في الرياض وجدة.
   - **7 أندية رياضية وجيم وسبا** في الرياض وجدة والدمام ومكة.
   - **7 معارض وصالات عرض سيارات** في الرياض وجدة والدمام.
   - موجودة بالكامل في `ksa_b2b_real_leads.json` و `ksa_b2b_real_leads.csv`.

2. **📲 نظام الإرسال المزدوج للعملاء عبر الواتساب:**
   - **الوضع الأوتوماتيكي (Pairing Code 8-Digits):** ربط الواتساب مباشرة بالسيرفر عن طريق كود من 8 أرقام من الموبايل بدون الحاجة لكاميرا أو لابتوب، مع إرسال تلقائي بفاصل زمني آمن (35 ثانية بين كل رسالة) لحماية الرقم من الحظر + رد تلقائي بالذكاء الاصطناعي 24/7 على أي عميل يرد.
   - **الوضع الآمن بضغطة زر (`wa.me`):** إرسال فوري لعروض (إيجار الأجهزة والريفيل الشهري + معاينة مجانية 48 ساعة + التعطير المركزي HVAC) بضغطة زر من الجوال.

3. **📐 حاسبة المساحة الذكية وكتالوج Smell & Smile الكامل:**
   - حساب الحجم بالمتر المكعب ($\text{م}^3$) وترشيح الجهاز الأنسب (`AC601 Mini`, `A323`, `AC105`, `AC106`, `AC100`, `ECHO`, `AC Home`, `AC 900 Elite`, `AC250/600 ULTRA`, `SE2500 & SE5000 HVAC`) مع الزيوت العطرية النقية (`هوتيل بلس`, `روح الرياض`, `روح المدينة`, `إماجين`, `فريش كلين`, `بلوم`).

4. **🔄 دفتر العملاء ومنبه الريفيل الشهري (30-Day Refill CRM):**
   - متابعة عقود الإيجار وتجديد الزيوت العطرية كل 30 يوماً مع التصدير إلى Excel/CSV.

## 🚀 طريقة التشغيل المحلي أو السحابي (Cloud)

```bash
npm install
npm start
```

ثم افتح المتصفح على: `http://localhost:3000`
